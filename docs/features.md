# 기능 개요

## 1. 환영 메시지

- 새 멤버가 서버에 들어오면 설정된 **환영 채널**로 메시지를 보냅니다.
- 이모지를 포함한 환영 문구를 사용합니다.
- 환영 채널은 관리자가 `/config welcome #채널`로 설정합니다.

## 2. 티켓 (비공개 스레드)

- **비공개 스레드**로 티켓을 생성해 채널 난립을 줄입니다.
- `/ticket panel`로 패널 메시지(버튼)를 띄우고, 버튼 클릭 시 스레드가 생성됩니다.
- 티켓을 연 사람과, 설정된 지원팀 역할/유저가 자동으로 스레드에 초대됩니다.
- 스레드 안에서 **클레임 / 언클레임 / 닫기** 버튼 또는 슬래시 명령으로 담당 지정·종료가 가능합니다.
- 닫을 때 트랜스크립트가 생성되어 설정된 채널로 업로드되고, 스레드는 잠금·보관됩니다.

자세한 흐름과 설정은 [티켓 상세 가이드](ticket.md)를 참고하세요.

## 3. 인사 답장

채팅 메시지에 특정 단어가 포함되면 봇이 해당 메시지에 **답장(reply)**으로 인사합니다.

| 단어   | 봇 답장 예시                |
| ------ | --------------------------- |
| 안녕   | 안녕! 👋                    |
| 굿모닝 | 굿모닝! ☀️ 좋은 아침이에요~ |
| 잘자   | 잘 자요! 🌙 좋은 밤 되세요~ |

## 4. 로그

다음 이벤트가 **로그 채널**로 Embed 형태로 전송됩니다. 로그 채널은 `/config log #채널`로 설정합니다.

- 서버 입장
- 메시지 삭제
- 메시지 수정
- 역할 부여/제거
- 음성 채널 입장/퇴장/이동
