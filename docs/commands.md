# 명령어 참조

관리자 권한이 있는 사용자만 사용할 수 있는 명령어입니다.

## `/config`

환영 메시지·로그 채널 등 서버별 설정을 관리합니다.

| 하위 명령               | 설명                                                |
| ----------------------- | --------------------------------------------------- |
| `/config welcome #채널` | 환영 메시지를 보낼 채널 설정. 채널을 생략하면 해제. |
| `/config log #채널`     | 로그를 보낼 채널 설정. 채널을 생략하면 해제.        |
| `/config show`          | 현재 설정(환영 채널, 로그 채널) 보기.               |

---

## `/ticket`

티켓 패널 및 티켓 관련 설정·동작을 관리합니다.

| 하위 명령                       | 설명                                                           |
| ------------------------------- | -------------------------------------------------------------- |
| `/ticket panel`                 | 명령을 실행한 채널에 "티켓 열기" 버튼 메시지 생성.             |
| `/ticket set-transcripts #채널` | 티켓 종료 시 트랜스크립트를 보낼 채널 설정.                    |
| `/ticket add-support-role`      | 티켓 생성 시 자동 초대할 **역할** 추가.                        |
| `/ticket add-support-user`      | 티켓 생성 시 자동 초대할 **유저** 추가.                        |
| `/ticket show`                  | 현재 서버의 티켓 설정 요약(트랜스크립트 채널, 지원 역할/유저). |

다음 명령은 **티켓 스레드 안에서만** 사용할 수 있습니다.

| 하위 명령                | 설명                                              |
| ------------------------ | ------------------------------------------------- |
| `/ticket claim`          | 이 티켓을 자신이 담당함.                          |
| `/ticket unclaim`        | 담당 해제.                                        |
| `/ticket close`          | 티켓 종료(트랜스크립트 생성 후 스레드 잠금·보관). |
| `/ticket transfer @유저` | 티켓 담당자를 지정한 유저로 변경.                 |
| `/ticket add @유저`      | 티켓 스레드에 유저 초대.                          |
| `/ticket remove @유저`   | 티켓 스레드에서 유저 내보내기.                    |

스레드 안에서는 **클레임 / 언클레임 / 닫기** 버튼으로도 같은 동작을 할 수 있습니다.
